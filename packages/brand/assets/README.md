# Brand assets

Drop these files here (overwrite when rebranding):

- `logo-light.svg` — primary logo on light backgrounds
- `logo-dark.svg`  — primary logo on dark backgrounds
- `mark.svg`       — icon-only mark (square)
- `og.png`         — 1200x630 social share image
- `favicon.ico`    — multi-size favicon

`apps/web` copies these into `public/brand/` at build time.
